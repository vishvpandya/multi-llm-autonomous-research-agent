# Repository instructions

Before changing this project, read `PROJECT_CONTEXT.md` completely.

After every material change to code, behavior, architecture, database schema, configuration,
dependencies, UI, tests, or known limitations, update `PROJECT_CONTEXT.md` in the same turn.
Keep its **Last updated**, **Current verified state**, **Project structure**, and relevant
technical sections accurate. Never place API keys, tokens, passwords, or other secrets in
the context file.

Run the appropriate tests before reporting completion and record the new test result in
`PROJECT_CONTEXT.md`. If verification cannot be performed, record that fact and the reason.
